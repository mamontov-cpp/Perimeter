# Редактор карт Perimeter — справка

Отдельное приложение для создания и правки миров и боевых карт Perimeter.
Эта справка описывает типовые сценарии работы. Технические детали форматов —
в `docs/map_editor.md` и `docs/architecture.md` репозитория.

## Быстрый старт

1. **File → Select Game Directory...** — укажите папку игры ( ту, что
   содержит `RESOURCE/`). Обычно это `build/Source/Debug` в дереве проекта.
2. **File → Load World...** (`Ctrl+O`) — выберите мир из `RESOURCE/Worlds`.
3. Редактируйте рельеф и цвета кистями, просматривайте в 2D или 3D.
4. **File → Save** (`Ctrl+S`) — мир сохраняется в свою папку (включая
   `cache.tga`/`map.tga`, которые игра читает при загрузке).

## Создание карты для «Сражения» (skirmish)

Боевая карта (`.spg`) — это точки появления игроков (спавны), камеры и
настройки игроков, привязанные к миру. Рельеф живёт в самом мире.

### Вариант А: карта на существующем мире

1. Загрузите мир (**Load World**).
2. Правьте рельеф/цвета кистями и сохраните мир.
3. **File → Open Battle Map (.spg)...** — откройте существующую карту,
   использующую этот мир (например, `RESOURCE/Battle/COMPASS.spg`), либо
   создайте новую (вариант Б).
4. В панели **Battle Map** (клавиша `B`):
   - выберите игрока в списке;
   - **Move to View Centre** — поставить спавн группы игрока в центр
     текущего обзора (фрейм + сквад + юниты + камера переезжают вместе,
     высота корректируется по рельефу автоматически);
   - **Edit Properties...** — имя, тип игрока (человек/AI), фракция,
     цвет, клан, сложность, гандикап;
   - **Go To** (двойной клик) — перейти к спавну игрока.
5. **File → Save Battle Map** — сохранить; **Save Battle Map As...** —
   сохранить под новым именем в `RESOURCE/Battle` или `RESOURCE/Worlds`.
6. Проверьте карту валидатором: **Tools → Validate Battle Map...**
7. Запустите игру — карта появится в списке «Сражения».

### Вариант Б: новая карта с нуля

1. **File → New World...** — мастер нового мира:
   - имя мира и мир-шаблон (из него копируются палитры и текстуры);
   - рельеф: **плоский** (высота гео-слоя; должна быть ниже нулевой
     толщины зеропласта) или **генерация** (процедурный рельеф игры);
   - размер карты (степень двойки, например 11 = 2048×2048), высота
     зеропласта (`hZeroPlast`).
   Созданный мир сразу загружается и сохраняется.
2. Оформите рельеф кистями; расставьте зеропласт и места под базы.
3. **File → Save**.
4. **File → New Battle Map...** — выберите шаблон карты, число игроков
   (1–8) и задайте имя. Карта создаётся для загруженного мира; спавны
   разместятся по эллипсу вокруг центра карты — передвиньте каждый в
   удобное место (кнопка **New Battle Map...** есть и в панели
   **Battle Map**, клавиша `B`).
5. Сохраните карту и проверьте в игре.

Совет: `zeroLayerHeight` боевой карты берётся из параметра мира
`hZeroPlast` при создании; если мир правился — **Tools → Autofix: Set
zeroLayerHeight from World**.

## Кисти

Кисть выбирается на панели **Brush** (тулбар) или в меню **Edit → Brush
Type / Mode**. Левая кнопка мыши красит, удержание — непрерывный штрих.

### Типы кисти (эффекты)

| Кисть | Действие |
|---|---|
| **Raise / Lower** | поднять/опустить рельеф на величину *Strength* за проход |
| **Level to Zeroplast** | выровнять до высоты зеропласта и пометить клетки как зеропласт за один штамп, сила кисти не влияет (только режим Dam) |
| **Level to Height** | поставить рельеф ровно на заданную высоту за один штамп (спинбокс рядом с кистями); перекрывающиеся штампы не поднимают выше цели |
| **Color** | покрасить поверхность выбранным индексом палитры, не меняя высоту |
| **Image Decal** | штамп картинкой в цветах поверхности дамбы: кнопка сразу предлагает PNG/TGA/BMP (не больше 512 px по стороне), картинка сводится к ограниченному набору цветов Dam-палитры (k-means), новые цвета добавляются в палитру. Только режим Dam; прозрачные пиксели не красят |
| **Pick Color** | пипетка: взять цвет клетки под курсором |
| **Soot** | «гарь» — косметическая тёмная пометка |
| **Very Light Dam** | очень лёгкая дамба (специальная запись палитры дамба) |

### Режимы (слой)

- **Geo** — правка гео-слоя (основной рельеф). Дамбы не затрагиваются:
  поднятие под дамбой поднимает гео под ней, краска ложится только на
  не-дамбовые клетки.
- **Dam** — правка слоя дамбы (плато зеропласта): поднятие выращивает
  дамбу (не ниже гео — инвариант игры), опускание снимает её до гео.
  Зеропластовые кисти и **Image Decal** доступны только в этом режиме.

### Формы (штамп)

- заполненный круг / квадрат;
- контур круга / квадрата;
- **правильный многоугольник** (заполненный и контур): вершины лежат на
  окружности радиуса кисти (как у круга); **число вершин** (3–20) и **угол
  первой вершины** (0–360°, циклический) задаются двумя спинбоксами рядом
  со спинбоксом радиуса — активны только при выбранной полигональной форме.
  Угол 0° — вершина на восток (+x), рост угла идёт по часовой стрелке;
- линия — два клика (начало, конец), штампы вдоль отрезка;
- **картинка-маска** (**Load Image**): любое PNG/JPG/BMP/TGA становится
  штампом; прозрачные пиксели не красят; масштаб маски — спинбокс рядом.
- **Image Decal** — своя геометрия: штамп ровно по размеру картинки
  (масштаб — тот же спинбокс, что у картинки-маски).

Для незаполненных форм (контур круга, контур квадрата, контур
многоугольника, линия) рядом со
спинбоксом радиуса доступен **спинбокс толщины** — ширина полосы в клетках.
Полоса растёт **внутрь** от внешнего края, поэтому широкий штрих не выходит за
пределы обычного отпечатка кисти. Толщина 1 — прежняя одно-клеточная граница;
для линии 1 — ровно путь Брезенхэма. Значение ограничено габаритом штампа
(2·радиус+1).

### Image Decal (картинка цветами дамбы)

Кнопка **Image Decal** — одновременно тип кисти и выбор файла. Порядок:

1. Выберите картинку (PNG/TGA/BMP, не больше 512 px по каждой стороне —
   иначе редактор покажет ошибку).
2. Редактор считает, сколько цветов картинки отсутствует в Dam-палитре и
   сколько её входов свободно. Если свободных меньше двух, а «чужих» цветов
   больше двух — появится ошибка о нехватке цветов (палитру надо освободить).
3. Картинка сводится к ограниченному набору цветов Dam-палитры (k-means:
   существующие цвета переиспользуются, недостающие добавляются в свободные
   входы палитры). Панель **Palette** сразу показывает новые цвета.
4. Клик/протяжка ставит картинку на дамбу: каждый пиксель красит клетку
   своим индексом палитры. Высота не меняется, прозрачные (и «почти
   прозрачные») пиксели не красят вообще, клетки без дамбы пропускаются.
5. Спинбокс масштаба рядом увеличивает/уменьшает штамп (100 % — исходный
   размер картинки, пиксели не сглаживаются).

Один штамп — одна запись Undo.

### Параметры

- **Radius** — полуразмер штампа в клетках (0–512; штамп до 1025×1025
  клеток). Лимит — редакторский, игровые радиусные таблицы Terra на это
  не опираются.
- **Strength** — шаг Raise/Lower за штамп. Влияние на Level to Zeroplast он
  не оказывает: та кисть доходит до высоты зеропласта за один штамп.
- **Height** — целевая высота кисти Level to Height (0..255 вокселей); кисть
  ставит её абсолютно за один штамп, сила на неё не влияет.
- **Undo/Redo**: `Ctrl+Z` / `Ctrl+R` (или `Ctrl+Y`). Каждый штрих — одна
  запись истории; импорт изображения на карту — тоже один шаг.

## Палитры и цвета

Панель **Palette**: две сетки 256 цветов — Geo (в `inGeo.act` +
`geoPal.xml`) и Dam (в `inDam.act`). Клик — выбрать цвет кисти, двойной
клик — изменить RGB (изменения применяются сразу и сохраняются в мир).
Пипетка (Pick Color) берёт индекс из палитры слоя клетки.

## Просмотр и навигация

- **2D (TopDown)**: колесо — зум (1:1…вся карта), перетаскивание — пан.
- **3D (Oblique)**: кнопка на тулбаре или меню View. Вращение/наклон/
  подъём/фокус — кнопки тулбара или мышь (Alt+левая — орбита, средняя/
  правая — пан, колесо — фокус). Клавиши поворота/наклона — на кнопках.
  Абсолютный поворот камеры задаётся **спинбоксом градусов** рядом с кнопками
  поворота (0–360°, с циклическим переносом через 360°→0°): спинбокс всегда
  показывает текущий азимут (включая орбиту мышью и режим Camera Like in
  Game — там это psi игровой камеры), а его правка сразу поворачивает камеру.
- **Camera Like in Game** (меню View) — переключить 3D-вид на камеру игры:
  модель psi/theta/distance с игровым FOV (HardwareCameraFocus), наведённая
  на камеру первого игрока загруженного мира (сплайн «Camera0» из
  `.spg` мира; для FORTOP — наклонный вид на спавн первого игрока, для
  миров без камер — вид сверху по умолчанию игры). Жёлтая рамка миникарты
  следует за игровым фрустумом. Управление: колесо — дистанция (зум игры),
  Alt+левая — psi/theta, средняя/правая — пан («тащить рельеф»).
- **Camera Like in Editor** (меню View) — вернуть редакторскую камеру 3D.
- **Chunky / Smooth** — пиксельный вид или сглаженный «как в игре».
- **Grid** — сетка-оверлей; шаг задаётся спинбоксами W/H (в клетках).
- **Dim Geo** — приглушение гео-слоя («как в игре» вне энергополя ядра).
- **Freeze Dam** — фон прокручивается только гео-слоем, дамба остаётся на
  месте (удобно искать ровные места).
- **Minimap** — панель-миникарта; клик перемещает обзор, рамка показывает
  видимую область. Картинка обновляется правками террейна сразу (кисть,
  откат/повтор), без необходимости сохранять мир.
- Клик в 3D-виде красит клетку под курсором (кисть работает и в 3D).

## Параметры мира

**File → World Parameters...**:

- `hZeroPlast` — высота зеропласта (применяется сразу);
- степени генерации (GeoNet/Section/MinimalSquare) — пишутся в
  `world.ini`, применяются при перезагрузке мира или генерации рельефа;
- **формат `output.vmp`** — S2T0 (без сжатия) или S2T1 (zlib); конвертация
  выполняется сразу и поддерживается при каждом сохранении;
- масштаб 3D-шума гео-слоя (`ScalingXYZ`, функция);
- **цвет зеропласта** — хранится в `Perimeter.ini` и общий для всех карт
  этой установки игры.

## Маркеры

Панель **Markers** (клавиша `K`): точки/зоны/юниты/здания с подписью,
заметкой, цветом и (для зон) радиусом. Добавляются в центр текущего обзора,
Go To — переход. Хранятся в файле `<мир>.medit.json` рядом с папкой мира;
игра их не читает — это заметки для редактора.

## Изображения

Меню **File → Images**:

- **Import Image onto Map...** — раскрасить поверхность картинкой
  (RGB → ближайший цвет палитры слоя клетки; индексированный TGA → индексы
  как есть). Фильтры: красить гео, красить дамбу. Один шаг Undo.
- **Import up.tga** — обложка мира 512×512 (игрой не используется).
- **Import leveledSurfaceTexture.tga** — текстура выровненных зон
  (палитровый TGA, степень двойки, ≤ размера карты).
- **Export Heightmap / Export Top View** — выгрузка высот (8-бит серый
  TGA) и вида сверху (24-бит TGA).

## Валидация

Меню **Tools**:

- **Validate World...** — файлы мира, размеры, `hZeroPlast`, палитры,
  текстуры, `hardness.bin`; объёмный баланс грунта относительно
  зеропласта (дисбаланс = предупреждение о будущем импорте/экспорте
  грунта);
- **Validate Battle Map...** — существование мира, спавны в границах,
  уникальные имена игроков, камеры;
- **Autofix** — нормализовать `playersShufflingIndices`, выставить
  `zeroLayerHeight` из мира, перегенерировать `cache.tga`/`map.tga`.

## Горячие клавиши

| Клавиша | Действие |
|---|---|
| `Ctrl+O` | загрузить мир |
| `Ctrl+S` | сохранить мир |
| `Ctrl+Shift+S` | сохранить мир как |
| `Ctrl+Z` / `Ctrl+R`, `Ctrl+Y` | undo / redo |
| `F5` | пересканировать список миров |
| `Ctrl+W` | выгрузить мир |
| `P` | показать/скрыть палитру |
| `K` | показать/скрыть маркеры |
| `B` | показать/скрыть панель боевой карты |
| `F1` | эта справка |

## Важно знать

- Все правки мира применяются в памяти; пока не нажат **Save**, файлы на
  диске не меняются (кроме параметров, помеченных как применяемые сразу).
- Изменение степеней генерации у загруженного мира вступает в силу только
  после его перезагрузки.
- Маркеры (`*.medit.json`) — часть редактора; игра их игнорирует. Файлы
  `.gmp`/`.dat` рядом с `.spg` редактор не трогает.
- После сохранения мира полезно перегенерировать/проверить `cache.tga` —
  редактор делает это автоматически при каждом сохранении.
- Новую карту обязательно проверяйте в самой игре (Tools-валидатор ловит
  только структурные проблемы).
