# Редактор карт Perimeter (`map_editor`)

Отдельное Qt-приложение для редактирования миров и боевых карт Perimeter.
Исходники — `Source/MapEditor/`; исходники игры (Terra, tx3d, Game, Util…)
не изменяются. Технические решения и находки: `docs/architecture.md`,
`docs/context.md`; план — `docs/map_editor_plan.md`.

## Сборка

Требуется: CMake ≥ 3.24, Qt 6 (Widgets; Qt5 принимается с предупреждением),
MSVC 2022+ (или совместимый компилятор; игра собирается VS 2022).

```bat
cmake -S . -B build -G "Visual Studio 18 2026" ^
      -DOPTION_MAP_EDITOR=ON ^
      -DMAP_EDITOR_QT_PREFIX=D:/SDKs/Qt/6.12.0/msvc2022_64
cmake --build build --config Release --target map_editor -- -m
```

- `OPTION_MAP_EDITOR` (по умолчанию OFF) — игровая сборка не меняется.
- `MAP_EDITOR_QT_PREFIX` — путь к Qt (или стандартный `CMAKE_PREFIX_PATH`).
- Бинарник: `build/Source/Debug/Release/map_editor.exe` (windeployqt
  копирует Qt-рантайм рядом автоматически).
- Headless-тесты: `build/Source/Debug/Release/map_editor_tests.exe`,
  запускать из папки игры (содержит `RESOURCE/`): все проверки идут во
  временной копии `%TEMP%\map_editor_roundtrip`, папка игры не изменяется.

## Запуск и первый шаг

1. `File → Select Game Directory...` — папка игры (содержит `RESOURCE/`).
2. `File → Load World...` — мир из `RESOURCE/Worlds/*`.

Все правки рельефа/цвета делаются кистями (панель Brush на тулбаре);
Undo `Ctrl+Z` / Redo `Ctrl+R`/`Ctrl+Y`. Мир сохраняется через `File → Save`
(`Ctrl+S`) — пишет `output.vmp`, палитры, `world.ini`, `hardness.bin`
(если был), `cache.tga`, `map.tga`.

## Справка

**Help → Map Editor Help...** (`F1`) — встроенное руководство (открывается
в отдельном окне, не мешает работе). Текст живёт отдельным файлом
`map_editor_help.md` рядом с исполняемым файлом редактора (копируется
сборкой из `Source/MapEditor/data/`); его можно править без пересборки.

## Возможности

### Миры
- **Просмотр**: 2D сверху (зум 1:1…fit, сетка с настраиваемым шагом,
  затемнение гео), наклонный 3D-вид (поворот/наклон/подъём/фокус,
  chunky/smooth), миникарта с прямоугольником вида.
- **Кисти**: подъём/опускание/выравнивание (Geo/Dam режимы), уровень до
  произвольной высоты, зеропласт (поставить/снять/гарь/very light dam),
  цвет (с учётом слоя клетки), пипетка; формы: круг/квадрат (заливка/контур),
  линия, картинка-маска (альфа 0 = не красить).
- **Палитры**: редактирование Geo/Dam RGB (двойной клик), синхронизация
  `geoPal.xml` при сохранении.
- **World Parameters** (`File → World Parameters...`): `hZeroPlast` (в живую),
  степени генерации (в `world.ini`, применяются после перезагрузки мира),
  сжатие `output.vmp` S2T0/S2T1 (конвертация сразу и при каждом сохранении),
  3DF-параметры гео-шума, цвет зеропласта (`Perimeter.ini [TD] Color
  ZeroLayer` — общая для игры).
- **Новый мир** (`File → New World...`): имя, шаблон (палитры/текстуры
  копируются из существующего мира), плоский рельеф на выбранной высоте
  гео-слоя или процедурная генерация (`buildWorld`), параметры карты.
  Созданный мир сразу загружается и сохраняется.
- **Изображения** (`File → Images`):
  - Import Image onto Map — раскраска `SurBuf` из PNG/JPG/BMP/TGA
    (RGB → ближайший индекс палитры слоя клетки; indexed TGA → индексы
    как есть); фильтры «красить гео/дамбу»; один шаг Undo;
  - Import up.tga — любая картинка → `up.tga` 512×512 24-бит;
  - Import leveledSurfaceTexture.tga — с валидацией (палитровый TGA,
    степень двойки, ≤ размера карты) и живой перезагрузкой;
  - Export Heightmap (8-бит серый TGA, `SGetAlt >> 5`) и Export Top View.
- **Маркеры** (док Markers, клавиша K): точки/зоны/юниты/здания с подписью,
  заметкой, цветом; сайдкар `RESOURCE/Worlds/<мир>.medit.json` (только для
  редактора, игра его не читает); Go To — переход к маркеру.

### Боевые карты (`.spg`)
- **Open Battle Map** (`File`): `RESOURCE/Battle/*.spg`, `RESOURCE/Worlds/*.spg`;
  мир из `worldName` загружается автоматически. Формат — XPrm-текст
  (`MissionDescriptionPrm` + `SavePrm`); файл воспроизводится байт-в-байт,
  если правки его не касаются (неизвестные узлы — контролы UI, триггеры —
  сохраняются как есть). `.gmp`/`.dat` игнорируются полностью.
- **Панель Battle Map** (клавиша B): игроки с координатами спавна, Go To,
  Move to View Centre (двигает фрейм + сквад + стабильную позицию + юнитов
  фрейма + камеру; z корректируется на разницу высот рельефа), Edit
  Properties (имя/тип/фракция/цвет/клан/сложность/гандикап), New Battle Map
  (шаблон + число игроков 1..8 + спавны по эллипсу + `zeroLayerHeight`
  из текущего мира).
- **Save / Save As**: в `RESOURCE/Battle` или `RESOURCE/Worlds`, с
  предупреждением о перезаписи.
- Оверлей спавнов рисуется в 2D-виде.

### Валидация (`Tools`)
- **Validate World**: обязательные файлы, размеры (степень двойки ≤ 16384),
  `hZeroPlast` 0..255, палитры (768 байт), `leveledSurfaceTexture.tga`,
  заголовок `hardness.bin`; **объёмный баланс** (T9.3): объём грунта выше
  плоскости зеропласта против объёма впадин, допуск в % от объёма впадин —
  при выходе предупреждение, что выравнивание потребует импорта/экспорта
  грунта.
- **Validate Battle Map**: мир существует, спавны в границах карты (с
  переходом к проблемному месту), имена игроков уникальны, камеры на
  каждого игрока, `playersShufflingIndices` покрывает всех.
- **Автофиксы**: нормализовать shuffling indices; выставить
  `zeroLayerHeight` из мира; перегенерировать `cache.tga`/`map.tga`.

## Форматы (кратко)

| Файл | Что редактор делает |
|---|---|
| `output.vmp` | S2T0 при сохранении; S2T1 — опция (конвертация тем же zlib-кодом, что игра) |
| `world.ini` | правки сохраняют формат/комментарии/неизвестные ключи байт-в-байт |
| `inGeo.act`/`inDam.act` | 768 байт RGB; плюс синхронизация `geoPal.xml` |
| `cache.tga`/`map.tga` | регенерируются при каждом сохранении (тот же растр, что вьюпорт) |
| `up.tga` | не читается игрой; редактор пишет 512×512 24-бит |
| `hardness.bin` | обновляется только если уже существовал |
| `*.spg` | XPrm-текст; байт-сохраняющие правки, `.gmp`/`.dat` не трогаются |
| `<мир>.medit.json` | маркеры (сайдкар, только для редактора) |

## Ограничения

- Изменение степеней генерации (`GeoNet Power` и др.) у **загруженного**
  мира пишется в `world.ini` и применяется только после перезагрузки мира
  (буферы уже выделены под текущие размеры).
- `Minimal Square Power` в `world.ini` фактически игнорируется загрузчиком
  игры (квиры — `docs/context.md`); редактор сохраняет значение как есть.
- Цвет зеропласта — глобальная настройка игры (одна на все карты), хранится
  в `Perimeter.ini`, не в мире.
- Оверлеи (маркеры, спавны, сетка) рисуются в 2D-виде; в 3D видна только
  сетка-плоскость.
- Папки `mods/*` не сканируются.
- Валидация объёмов использует видимую поверхность (`SGetAlt`), дамба
  приоритетна.

## Приёмка в игре (T10.3, ручной чек-лист)

Планируемые проверки (не автоматизированы): мир открывается в бою (рельеф,
цвета, зеропласт, дамбы совпадают с редактором); новая боевая карта
запускается в «Сражении» (игроки на своих спавнах, камеры на месте, базы
целы); правка существующей карты не ломает базы/камеры/скрипты;
сжатый S2T1 мир грузится игрой.
